# Levee

Liquidity that holds its line.

Levee is managed liquidity on Robinhood Chain: one-token zaps into concentrated liquidity
positions, range orders that earn while they wait, automated position keeping, LP vaults
(plain, hedged and structured notes), Levee's own pools, a pre-market perp and token launches.
Protocol fees buy back and burn $LEVEE.

- App: [levee.trade](https://levee.trade)
- Docs: [levee.trade/docs](https://levee.trade/docs)
- X: [@TryLeveeTrade](https://x.com/TryLeveeTrade)

## Open source contracts

Every contract Levee has deployed is public in
[levee-contracts](https://github.com/LeveeTrade/levee-contracts): the source, the full test
suite and the deploy scripts. The repository compiles to exactly the bytecode on chain, so
anyone can check that what they read is what runs. Security reports go through the
repository's private vulnerability reporting.
